# 시간 규칙

대국 시계 규칙이다. 온라인 대국의 시계는 서버가 기준이며 앱은 표시만 한다.

## 기본 시간과 초읽기 — 확정

- 각자 기본 시간 **5분**을 가진다.
- 기본 시간을 다 쓰면 초읽기로 넘어간다. 초읽기는 **30초, 3회**다.
- 초읽기 중에는 한 수를 30초 안에 두면 초읽기 횟수가 줄지 않고 다음 수에서 다시 30초를 받는다.
- 30초 안에 두지 못하면 초읽기 1회를 쓰고 다시 30초를 받는다.
- 초읽기 3회를 모두 쓴 뒤 30초 안에 두지 못하면 시간패다.
- 한수쉼도 한 수로 보고 시계를 넘긴다.

## 상차림 시간 — 확정

- 상차림은 각자 **20초** 안에 고른다. 한이 먼저 고르고, 초는 한의 상차림이 확정된 뒤 20초를 받는다.
- 20초 안에 확정하지 않으면 그 순간 화면에 골라 둔 상차림으로 자동 확정한다. 아무것도 누르지 않았으면 기본값(마상마상)이다.

## 시간 연장

대국 중 시간 연장권을 써서 자기 초읽기 횟수를 늘린다. 시간 연장권을 얻는 방법과 가격은 [monetization.md](../monetization.md)에서 정한다.

### 확정

- 1회 쓰면 초읽기 횟수가 **2회** 늘어난다. 예: 30초 3회 → 30초 5회.
- 기본 시간 중에도, 초읽기 중에도 쓸 수 있다. 기본 시간에 시간을 더하지는 않는다.
- 급수가 걸린 대국에서도 쓸 수 있다. 시간을 더 써도 실력 차이는 넘을 수 없다.
- 한 대국에서 **2회**까지 쓴다. 무제한이면 대국이 늘어진다.
- 쓰면 상대 화면에 사용 사실을 표시한다.
- 빠른 대국, 방 대국, 신청 대국 모두 쓸 수 있다.
