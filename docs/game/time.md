# 시간 규칙

대국 시계 규칙이다. 온라인 대국의 시계는 서버가 기준이며 앱은 표시만 한다.

## 기본 시간과 초읽기 — 확정

- 각자 기본 시간 **5분**을 가진다.
- 기본 시간을 다 쓰면 초읽기로 넘어간다. 초읽기는 **30초, 3회**다.
- 초읽기 중에는 한 수를 30초 안에 두면 초읽기 횟수가 줄지 않고 다음 수에서 다시 30초를 받는다.
- 30초 안에 두지 못하면 초읽기 1회를 쓰고 다시 30초를 받는다.
- 초읽기 3회를 모두 쓴 뒤 30초 안에 두지 못하면 시간패다.
- 한수쉼도 한 수로 보고 시계를 넘긴다.

## 상차림 시간 — 미정

- 상차림을 고르는 데 쓰는 시간과, 시간 안에 고르지 않으면 어떻게 할지.

## 시간 연장 — 미정: 유료 아이템으로 기획

대국 중 자기 시간을 늘리는 유료 아이템이다. 다음 항목을 정해야 한다.

- 한 번에 늘어나는 시간, 한 대국에서 쓸 수 있는 횟수
- 기본 시간과 초읽기 중 어디에 더하는지
- 급수가 걸린 대국에서 쓸 수 있는지. 쓸 수 있으면 돈으로 승률을 사는 구조가 되어 공정성 불만이 생길 수 있다
- 상대에게 사용 사실을 알리는지
- 친구 대국, 방송인 모드 등 대국 종류별 허용 여부
- 가격과 지급 방식(개별 구매, 묶음, 구독 포함 여부)
