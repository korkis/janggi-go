# 좌표와 기보 표기

앱, 서버, AI 분석이 수와 국면을 주고받는 형식이다. 이 문서 전체가 **제안** 상태이며 `janggi_core` 구현 전에 확정한다.

## 목표

- 앱, 대국 서버, DB, AI 엔진이 같은 문자열로 수와 국면을 주고받는다.
- AI 엔진(Fairy-Stockfish)과 변환 없이, 또는 최소한의 변환으로 주고받는다.
- 사용자에게 보여주는 한국식 기보 표기는 내부 형식과 분리한다.

## 좌표 — 제안

- 초 진영이 아래에 오도록 판을 놓고 본다.
- 세로줄은 왼쪽부터 `a`~`i`, 가로줄은 아래부터 `1`~`10`이다.
- 칸은 `e2`, `a10`처럼 세로줄 문자와 가로줄 숫자를 붙여 쓴다.
- 초의 궁은 처음에 `e2`, 한의 궁은 `e9`에 놓인다.

## 수 — 제안

- 출발 칸과 도착 칸을 붙여 쓴다. 예: `b1c3`, `e7e6`, `a10a8`
- 한수쉼은 `pass`로 쓴다.
- 이 형식은 체스 엔진의 UCI 표기와 같은 방식이다. Fairy-Stockfish의 장기 표기(가로줄 `10` 처리, 한수쉼 표기)와 정확히 일치하는지는 AI 연동 전에 확인하고, 다르면 서버의 엔진 연결 부분에서만 변환한다.

## 국면 — 제안

- 체스의 FEN과 같은 방식으로 한 줄 문자열로 표기한다. 가로줄 10부터 1까지 `/`로 구분하고, 빈 칸 수는 숫자로 쓴다. 이어서 차례를 쓴다.
- 기물 문자는 Fairy-Stockfish 장기 FEN을 따른다. 초는 대문자, 한은 소문자다.

| 기물 | 문자 |
|---|---|
| 궁 | `K` |
| 사 | `A` |
| 상 | `B` |
| 마 | `N` |
| 차 | `R` |
| 포 | `C` |
| 졸·병 | `P` |

- 기물 문자와 FEN의 차례 표기는 Fairy-Stockfish 연동 시 실제 값과 대조해 확정한다.

## 기보 — 제안

한 대국의 기보는 다음 항목으로 저장한다. 처음 국면과 수 목록만 있으면 어떤 국면이든 재생할 수 있다.

| 항목 | 내용 |
|---|---|
| 처음 국면 | 상차림과 접장기가 반영된 국면 문자열 |
| 수 목록 | 위 수 표기의 배열 |
| 결과 | 승자, 끝난 사유(외통, 기권, 시간패, 점수 판정 등), 점수 |
| 시간 정보 | 각 수에 쓴 시간 |

## 한국식 기보 표기 — 미정

- 사용자에게 보여주는 기보(예: 복기 화면의 수 목록)는 한국에서 쓰는 표기로 보여준다.
- 표기 방식은 확정되면 이 문서에 추가한다. 내부 형식과의 변환은 `janggi_core`가 담당한다.
