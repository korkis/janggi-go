# 급수

사용자의 실력을 나타내는 급수와, 급수를 정하는 레이팅이다. 각 항목은 **확정**, **제안**, **미정**으로 표시한다.

## 급수 범위 — 확정

- 18급부터 1급, 그다음 1단부터 9단까지 모두 27단계다. 9단이 가장 높다.
- 처음 가입한 사용자는 18급에서 시작한다.

## 레이팅 — 확정

- 급수는 사용자에게 보이지 않는 레이팅 점수로 정한다. 레이팅이 급수 구간을 넘으면 급수가 바로 오르고, 아래로 내려가면 바로 내려간다. 강급을 막는 보호 장치는 두지 않는다.
- 레이팅 숫자는 사용자에게 보여주지 않는다. 화면에는 급수와 다음 급수까지의 진행 정도만 보여준다.
- 급수에 반영하는 대국은 **빠른 대국만**이다. 방 대국, 신청 대국, 접장기 대국은 친선전으로 보고 반영하지 않는다. 아는 사람끼리 일부러 져 주며 급수를 올리는 것을 막기 위해서다.
- 기권, 시간패, 대국 중 나가기는 모두 패로 계산한다.
- 레이팅 계산은 대국 서버(`server/game`)가 대국이 끝날 때 한다. 앱은 결과만 받아 보여준다.

## 계산 방식 — 제안

- Elo 방식을 쓴다. 이기면 오르고 지면 내려가며, 나보다 레이팅이 높은 상대를 이길수록 많이 오른다.
- 처음 가입하면 레이팅 1000점(18급)에서 시작한다.
- 대국 수가 적을 때는 한 판에 크게 움직여서 실력이 좋은 신규 사용자가 빨리 제 급수를 찾게 한다.

| 반영된 대국 수 | K 값 |
|---|---|
| 0~19판 | 80 |
| 20~99판 | 40 |
| 100판 이상 | 20 |

- 급수 구간은 50점마다 한 단계로 시작하고, 실제 분포를 보고 조정한다.

| 급수 | 레이팅 |
|---|---|
| 18급 | 1050 미만 |
| 17급 | 1050 이상 1100 미만 |
| … | 50점씩 한 단계 |
| 1급 | 1850 이상 1900 미만 |
| 1단 | 1900 이상 1950 미만 |
| … | 50점씩 한 단계 |
| 9단 | 2300 이상 |

- K 값과 급수 구간은 운영하면서 바꿀 수 있는 값이지만 알려지면 악용될 수 있으므로 `configs/app`이 아니라 서버 설정(`server/game`)에 둔다([dev_rules.md](../dev_rules.md)의 설정 저장).

## 화면 표시 — 제안

- 홈의 내 카드, 내 정보, 대국 결과에 급수와 다음 급수까지의 진행 막대를 보여준다. 진행 막대는 현재 급수 구간 안에서 레이팅이 어디쯤인지를 나타낸다.
- 진행 막대 옆에 "4급까지 약 3승"처럼 비슷한 레이팅의 상대를 이길 때 필요한 승수를 어림해 보여준다.
- 진행 막대는 18급이면 1000점부터 센다(1000 아래면 비어 있다). 9단은 다음 급수가 없어 진행 막대와 어림 승수를 보여주지 않는다. 아직 급수 대국을 두지 않았으면 어림 승수 없이 막대만 보여준다.
- 대국 결과에서는 이번 대국으로 늘거나 줄어든 막대 부분을 구분해 보여준다. 급수가 바뀌면 "4급으로 올랐어요", "6급으로 내려갔어요"를 알린다.
- 대국 결과에서 급수가 올랐으면 새 급수 구간의 처음부터, 내려갔으면 끝부터 바뀐 부분으로 그린다.

## 빠른 대국 매칭 — 제안

- 급수가 아니라 레이팅이 가까운 상대를 찾는다.
- 처음에는 레이팅 차이 100점 안에서 찾고, 10초마다 50점씩 넓혀 최대 400점까지 넓힌다.
- 이 값들도 서버 설정에 두고 사용자 수를 보고 조정한다.

## 미정

- 오래 대국하지 않은 사용자의 레이팅을 그대로 둘지.
- 레이팅 초기화나 시즌 제도를 둘지.
