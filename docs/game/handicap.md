# 접장기

한쪽이 기물 일부를 떼고 두는 대국이다. 주로 방송인이 이벤트 대국이나 콘텐츠로 시청자(하수)와 "차 떼고 한판" 같은 대국을 재미있게 두는 데 쓴다. 카카오장기에 없는 장기고의 차별점이다.

## 규칙 — 확정

- 일반 대국과 **모든 규칙이 같다.** 다른 것은 처음에 놓이는 기물뿐이다.
- 시간, 덤, 반복수, 한수쉼, 승패와 점수 판정 모두 [rules.md](./rules.md)와 [time.md](./time.md)를 그대로 따른다.
- 남은 기물 점수로 판정하므로 기물을 뗀 쪽은 점수가 낮은 상태로 시작한다. 이것이 접장기의 핸디캡이며, 이 조건이 싫으면 접장기를 두지 않는다.

## 떼는 기물 — 초안

- 접장기 대국은 급수에 반영하지 않는다([rank.md](./rank.md)).
- 기물을 떼는 쪽은 항상 한(나중에 두는 쪽)을 잡는다. 떼지 않는 쪽이 초를 잡고 먼저 둔다. 그래서 접장기 대국은 방 만들기·신청에서 진영을 따로 고르지 않는다.
- 기물을 떼는 쪽이 자기 기물 중 차, 포, 마, 상을 골라 뗀다.
- 여러 개를 조합해서 뗄 수 있다. 예: 차 하나, 포 둘, 차와 포 하나씩
- 접장기 대국은 방 만들기와 대국실의 신청에서 만든다([matching.md](./matching.md)). 방장(신청이면 신청한 사람)이 떼는 쪽(나 또는 상대)과 뗄 기물을 정한다. 빠른 대국에서는 쓸 수 없다.
- 뗄 기물은 판에 놓이는 순서대로 늘어놓은 기물 그림을 눌러 고른다. 그래서 같은 기물 두 개 중 왼쪽과 오른쪽을 따로 고를 수 있다.
