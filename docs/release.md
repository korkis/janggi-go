# 출시 계획

로드맵 3단계의 출시 순서, 출시 범위, 운영 배포로만 확인할 것, 규정 확인 결과다. 상품과 엽전은 [monetization.md](./monetization.md)에서 정한다.

각 항목은 **확정**, **초안**, **미정**으로 표시한다.

## 출시 순서 — 확정 (2026-11-05)

1. 웹 운영 배포와 안드로이드 비공개 테스트를 같이 시작한다. 실제 로그인, 앱 링크, 결제를 여기서 확인한다.
2. 그동안 iOS 심사를 넣는다.
3. 세 곳이 다 준비되면 함께 공개하고 방송인 섭외를 시작한다.

- 첫 유입을 놓치지 않기 위해서다. 주 사용자인 40~60대는 휴대폰으로 들어온다.
- 안드로이드는 3주 이상 잡는다. 2023-11-13 이후 만든 개인 계정은 테스터 12명이 14일 연속 참여한 뒤 프로덕션을 신청할 수 있고, 검토는 보통 7일 안쪽이다([Play Console 도움말](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko), 2026-11-05 확인). 조직 계정이 면제되는지는 이 페이지에 없어 확인하지 못했다.

## 출시 범위 — 확정 (2026-11-05)

넣는 것:

- 2단계에 만든 기능 모두. 접속자 탭은 사람이 적을 동안 `configs/app.onlineUsersVisible`로 꺼 둔다.
- 엽전, 상점, 결제, 광고, 시간 연장.
- 회원 탈퇴. 앱 안에서 할 수 있어야 한다(앱스토어 심사 기준). 지울 범위는 [database.md](./database.md)의 미정을 정한다.
- 이용약관과 개인정보처리방침 화면.
- 앱 최소 버전 안내. 서버와 맞지 않는 옛 앱에 업데이트 화면을 띄운다. 나중에 넣으면 첫 버전 사용자에게 띄울 수 없으므로 첫 버전에 넣는다.
- 아래쪽 탭([screens.md](./screens.md)의 홈).
- 효과음과 진동, 설정의 켜기·끄기.
- 크래시 수집(Firebase Crashlytics).

빼는 것: 박보장기, 카카오 로그인, AI 대국과 AI 코치(4단계).

## 운영 배포로만 확인할 것 — 초안

에뮬레이터로 확인할 수 없어 운영 배포 뒤 실제 기기에서 확인한다.

- 실제 구글, 애플 로그인.
- App Links, Universal Links, Install Referrer. 웹으로 받은 초대 링크가 앱의 같은 방으로 이어지는지.
- `apple-app-site-association`의 Content-Type(Hosting 에뮬레이터는 headers를 적용하지 않는다).
- 두 계정의 실제 대국, Cloud Tasks 예약 작업(시간패, 상차림 마감).

운영 배포 전에 채울 값:

- `assetlinks.json`의 Play App Signing SHA-256(지금은 개발 PC 디버그 키만 있다).
- AASA의 `APPLE_TEAM_ID`, Associated Domains, `invite.html`의 `APP_STORE_URL`.
- 운영 Firestore 규칙. [server.md](./server.md) 구현 순서 1번에 2026-11-30까지 열려 있다고 적힌 규칙이 운영에 남아 있는지 확인한다.

운영 배포는 사용자가 정한 때만 한다.

## 규정 확인 — 초안

법률 조언이 아니라 자료를 읽은 결과다. 출시 전에 전문가에게 확인한다.

- 사행성게임물은 베팅·배당을 내용으로 하거나 우연적인 방법으로 결과가 정해지는 게임 등으로서, 그 결과에 따라 재산상 이익이나 손실을 주는 것이다([생활법령정보](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=2858&ccfNo=2&cciNo=2&cnpClsNo=2), 2026-10-15 기준).
- 웹보드 게임은 베팅·배당을 모사한 카드게임, 화투, 스포츠 승부예측 등이다(같은 자료). 장기는 목록에 없다.
- 온라인 바둑은 웹보드 규제에 넣지 않기로 했고, 쟁점은 남의 대국에 거는 3자 베팅이었다([아이뉴스24, 2024-03-19](https://www.inews24.com/view/1698631)). 그 뒤의 변동은 확인하지 못했다.
- 확인하지 못한 것: 게임산업법 시행령 별표 2 제8호 원문. 게임물관리위원회 사이트는 자동 조회가 막혀 있어 등급 분류 절차도 읽지 못했다.

### 전문가에게 물을 것

- 참가비와 승패 보상. 유상 엽전을 참가비로 내고 승패에 따라 다른 보상을 받는 구조가 베팅·배당이나 재산상 이익·손실에 해당하는지. 유상과 무상을 나누지 않는 안을 사용자가 골랐다(2026-11-05). 위험하다는 답이 나오면 참가비를 무상 엽전에서만 받거나 없앤다. **답을 받기 전에는 공개하지 않는다.**
