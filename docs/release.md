# 출시 계획

로드맵 3단계의 출시 순서와 범위, 운영 배포로만 확인할 것, 규정 확인, 구현 순서다. 상품, 엽전, 결제, 광고는 [monetization.md](./monetization.md)에서 정한다.

각 항목은 **확정**, **초안**, **미정**으로 표시한다. 규정 내용은 법률 조언이 아니라 자료를 읽은 결과이며 확인한 날은 2026-11-06이다.

## 출시 순서 — 확정 (2026-11-05)

1. 웹 운영 배포와 안드로이드 비공개 테스트를 같이 시작한다. 실제 로그인, 앱 링크, 결제를 여기서 확인한다.
2. 그동안 iOS 심사를 넣는다.
3. 세 곳이 다 준비되면 함께 공개하고 방송인 섭외를 시작한다.

- 첫 유입을 놓치지 않기 위해서다. 주 사용자인 40~60대는 휴대폰으로 들어온다.
- 사용자의 구글 계정에는 테스터 12명 요건이 걸리지 않는다(2026-11-06 사용자 확인). 비공개 테스트는 실제 확인을 위해 둔다.

## 출시 범위 — 확정 (2026-11-05)

넣는 것:

- 2단계에 만든 기능 모두. 접속자 탭은 사람이 적을 동안 `configs/app.onlineUsersVisible`로 꺼 둔다.
- 엽전, 상점, 앱 결제, 앱 광고, 시간 연장, 대국 중 놓아보기.
- 회원 탈퇴. 앱 안에서 할 수 있어야 한다(앱스토어 심사 기준). 지울 범위는 [database.md](./database.md)의 미정을 정한다.
- 이용약관과 개인정보처리방침 화면.
- 앱 최소 버전 안내. 서버와 맞지 않는 옛 앱에 업데이트 화면을 띄운다. 나중에 넣으면 첫 버전 사용자에게 띄울 수 없으므로 첫 버전에 넣는다.
- 아래쪽 탭([screens.md](./screens.md)의 홈).
- 효과음과 진동, 설정의 켜기·끄기.
- 빠른 대국 매칭 알림 하나(아래 "알림").
- 크래시 수집(Firebase Crashlytics).

빼는 것: 박보장기, 카카오 로그인, 웹 결제, 웹 광고, AI 대국과 AI 코치(4단계).

## 출시 국가 — 확정 (2026-11-06)

전 세계에 낸다. 스토어 소개는 한국어와 영어로 쓴다.

- **빼는 곳:** 중국 앱스토어. 게임에 정부 허가 번호를 요구한다([App in China](https://appinchina.co/blog/update-apples-new-requirements-for-games-on-the-apple-app-store-china/), 2020년 자료라 등록할 때 다시 본다).
- **유럽 등 광고 동의:** EEA, 영국, 스위스에 맞춤 광고를 내려면 구글 인증 동의 관리 도구가 필요하다([AdMob 도움말](https://support.google.com/admob/answer/13554020), [Flutter 안내](https://developers.google.com/admob/flutter/privacy/gdpr)). UMP SDK를 쓴다.
- **유럽 앱스토어 판매자 정보:** 개인 개발자 계정은 주소(또는 사서함), 전화, 이메일이 공개된다([App Store Connect 도움말](https://developer.apple.com/help/app-store-connect/manage-compliance-information/manage-eu-digital-services-act-compliance-information), [MacRumors](https://www.macrumors.com/2024/10/17/developers-eu-app-store-trader-requirements/)). 공개해도 된다고 사용자가 정했다(2026-11-06).
- **iOS 추적 동의:** ATT 창을 쓰지 않으면 광고 식별자가 0이 되어 수익이 줄 수 있다([플러그인 문서](https://pub.dev/packages/app_tracking_transparency)). UMP와 함께 띄운다(초안).
- **서버:** 대국 서버는 서울 하나다. 먼 나라는 지연이 크고 시계는 보정하지 않는다([server.md](./server.md)의 시계). 이대로 낸다(초안).

## 알림 — 확정 (2026-11-06)

종류는 하나다. 앱(안드로이드, iOS)에서 FCM으로 보내고 웹은 보내지 않는다.

- 빠른 대국을 기다리다 앱을 껐는데 상대를 찾으면 "상대를 찾았어요"를 보낸다.
- 찾으면 바로 대국을 만든다. 알림을 늦게 보면 상차림은 기본값으로 정해지고 접속 끊김패가 되어 급수에 반영된다(사용자가 고른 동작이다).
- 그 밖의 알림은 보내지 않는다. 대기 중이나 대국 중에 앱을 나갔다는 알림, 출석·이벤트 알림은 없다.

지금 서버와 다른 점(구현 때 바꾼다):

- 앱 연결이 모두 끊겨도 대기열에서 빼지 않는다. 얼마나 남길지는 `configs/app`에 둔다. 기본 30분(초안).
- 지금은 앱에 떠 있지 않은 후보를 건너뛴다. 앱을 끈 사람은 FCM 토큰이 있을 때만 후보로 넣는다. 다른 앱으로 넘어간 사람을 건너뛸지는 구현 때 이 알림과 함께 정한다.

## 효과음 — 확정 (2026-11-06)

- 무료 음원으로 수 두기, 기물 잡기, 장군, 초읽기 경고, 승리, 패배를 고른다. 상업적 이용이 되는 것만 쓰고 출처와 라이선스를 기록한다.
- 사용자가 듣고 이상한 것은 유료 음원으로 바꾼다. 파일만 갈아 끼우면 바뀌게 한다(코드는 소리 이름만 알고 파일 경로는 한 곳에 둔다).

## 연령 — 확정 (2026-11-06)

- 만 14세 미만은 가입할 수 없다. 약관에 적고, 로그인 창의 동의 문구에 넣는다([screens.md](./screens.md)의 로그인 창).
- 체크 칸 없이 동의 문구로 충분한지, 나라별 연령 기준은 확인하지 못했다.

## 운영 설정과 멈춤 스위치 — 확정 (2026-11-06)

문제가 되면 앱 업데이트 없이 Admin 웹에서 바로 멈출 수 있게 `configs/app`에 둔다. 값은 그 기능을 만드는 구현 순서에서 추가한다.

| 설정 | 끄거나 바꾸면 | 쓰는 경우 | 구현 순서 |
|---|---|---|---|
| 엽전 숫자(지급, 대국 보상, 쓰는 값) | 앱 업데이트 없이 값이 바뀐다 | 밸런스 조정 | 1, 2, 5, 6 |
| `entryFeeEnabled` | 참가비를 받지 않는다 | 판돈 해석 지적 | 1 |
| `timeExtensionEnabled` | 시간 연장을 멈춘다 | 대국 중 유료 혜택 지적 | 2 |
| `gamePracticeEnabled` | 대국 중 놓아보기를 멈춘다 | 같은 지적, 공정성 불만 | 2 |
| `chatEnabled` | 채팅을 멈춘다 | 욕설 사태, 검사 서비스 장애 | 4 |
| `signupEnabled` | 새 가입을 멈춘다. 기존 사용자는 그대로다 | 본인인증 지적 | 4 |
| `webEnabled` | 웹은 안내 화면만 보여준다 | 웹 등급 분류 지적 | 4 |
| `minAppVersion` | 옛 앱에 업데이트 화면을 띄운다 | 앱을 고친 뒤 옛 버전 차단 | 4 |
| `serviceNotice` | 공지를 띄우고 대국 시작을 막을 수 있다 | 점검, 긴급 상황 | 4 |
| `coinSaleEnabled` | 엽전 충전 판매를 멈춘다. 이미 산 엽전은 계속 쓴다 | 유상 재화 지적, 환불 문제 | 5 |
| `rewardedAdEnabled` | 보상형 광고를 멈춘다 | 광고 정책 문제, 보상 악용 | 6 |
| `bannerAdEnabled` | 배너 광고를 멈춘다 | 광고 계정 문제 | 6 |
| 앱을 끈 사람의 대기 시간 | 값이 바뀐다 | 오래된 매칭 알림 조정 | 8 |

- 앱에서 숨기는 것으로 끝내지 않고 서버 API도 같은 설정을 확인해 거절한다. 옛 앱과 조작된 앱도 멈추기 위해서다.
- 앱이 읽어 둔 값과 서버 캐시 때문에 화면에는 조금 늦게 반영될 수 있다. 바로 막는 것은 서버다.
- `configs/app`은 누구나 읽으므로 악용될 값(어뷰징 탐지 기준 등)은 넣지 않는다.
- Admin 웹의 설정 화면과 `adminUpdateAppConfig`의 범위 검사를 필드가 늘 때마다 함께 늘린다.

설정으로 못 고치는 것: 지난 운영에 대한 책임, 본인인증 도입(앱 업데이트 필요), 나라별 판매 중단(스토어 콘솔), 산 엽전 환불(스토어 환불과 약관 절차).

## 운영 배포로만 확인할 것 — 초안

에뮬레이터로 확인할 수 없어 운영 배포 뒤 실제 기기에서 확인한다.

- 실제 구글, 애플 로그인.
- App Links, Universal Links, Install Referrer. 웹으로 받은 초대 링크가 앱의 같은 방으로 이어지는지.
- `apple-app-site-association`의 Content-Type(Hosting 에뮬레이터는 headers를 적용하지 않는다).
- 두 계정의 실제 대국, Cloud Tasks 예약 작업(시간패, 상차림 마감).
- 실제 결제와 환불, AdMob 서버 콜백, FCM 알림.

운영 배포 전에 채울 값:

- `configs/app`의 새 필드. 서버를 배포하기 전에 `npm run init-app-config`를 실행한다([server.md](./server.md)의 `configs/app`).
- `assetlinks.json`의 Play App Signing SHA-256(지금은 개발 PC 디버그 키만 있다).
- AASA의 `APPLE_TEAM_ID`, Associated Domains, `invite.html`의 `APP_STORE_URL`.
- 운영 Firestore 규칙. [server.md](./server.md) 구현 순서 1번에 2026-11-30까지 열려 있다고 적힌 규칙이 운영에 남아 있는지 확인한다.

운영 배포는 사용자가 정한 때만 한다.

## HTML 페이지 — 초안

Flutter 화면은 검색 엔진과 AdSense 심사가 읽기 어려우므로 Hosting에 가벼운 HTML 페이지를 둔다. 초대 입장 페이지(`invite.html`)와 같은 방식이다.

- 장기 규칙, 접장기 설명. 검색 유입과 AdSense 승인을 돕는다. 내용은 [game/rules.md](./game/rules.md), [game/handicap.md](./game/handicap.md)를 쓴다.
- 이용약관, 개인정보처리방침. 스토어 등록에 쓸 주소이기도 하다.
- 앱으로 가는 버튼을 둔다. 내용 없는 페이지를 늘리지 않는다.

## 개인정보처리방침과 이용약관 — 초안

Claude가 초안을 쓰고 사용자가 읽은 뒤 공개한다.

### 국외 이전

계약 이행에 필요한 위탁·보관이면 별도 동의 없이 이전할 수 있고, 이전 사실과 근거를 처리방침에 공개한다([개인정보위 안내](https://pipc.go.kr/np/default/page.do?mCode=D060040000), 2차 자료로 보충). 이 사유를 쓰는 것을 전제로 초안을 쓴다.

| 받는 곳 | 나라 | 내용 | 비고 |
|---|---|---|---|
| Google (Firebase Auth) | 미국 | 이메일, 로그인 식별자 | |
| Google (Realtime Database) | 싱가포르 | 닉네임, 대국, 채팅, 접속 상태 | |
| Google (Crashlytics, FCM, AdMob) | 미정 | 크래시 기록, 기기 정보, 알림 토큰, 광고 식별자 | 위치를 문서로 확인한다 |
| OpenAI | 미국 | 채팅 메시지(검사용) | 위치와 보관 기간을 문서로 확인한다 |
| RevenueCat | 미국 | 사용자 ID, 구매 내역 | 위치를 문서로 확인한다 |

Firestore, 대국 서버, Functions는 서울에 있어 국외 이전이 아니다.

### 약관에 넣을 것

- 엽전: 유상과 무상의 구분, 쓰는 순서, 현금으로 바꿀 수 없음, 사용자끼리 오가지 않음.
- 청약철회: 쓰지 않은 유상 엽전과 상품은 7일 안에 철회할 수 있음. 계약 전에 기한과 방법을 알려야 하므로 구매 화면에도 적는다(전자상거래법 제13조, 2차 자료로 확인했다).
- 미성년자 결제 취소, 서비스 종료 때의 환불과 사전 고지.
- 금지 행위와 제재([moderation.md](./moderation.md)), 만 14세 미만 가입 불가.

## 규정 확인 — 초안

- 사행성게임물은 베팅·배당을 내용으로 하거나 우연적인 방법으로 결과가 정해지는 게임 등으로서, 그 결과에 따라 재산상 이익이나 손실을 주는 것이다([생활법령정보](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=2858&ccfNo=2&cciNo=2&cnpClsNo=2), 2026-10-15 기준).
- 웹보드 게임은 베팅·배당을 모사한 카드게임, 화투, 스포츠 승부예측 등이다(같은 자료). 장기는 목록에 없다.
- 온라인 바둑은 웹보드 규제에 넣지 않기로 했고, 쟁점은 남의 대국에 거는 3자 베팅이었다([아이뉴스24, 2024-03-19](https://www.inews24.com/view/1698631)). 그 뒤의 변동은 확인하지 못했다.
- 게임산업법 제12조의3에 온라인 게임 본인인증과 법정대리인 동의의 근거가 있다. 2025년 기준 간소화가 논의 중이었다([법률신문, 2025-06-09](http://www.lawtimes.co.kr/news/articleViewRedirect.html?temp_data=208672)). 장기고는 구글·애플·이메일 로그인만 쓰고 본인인증이 없다.
- 2026-10-01에 게임산업법 개정안이 국회를 통과했고 공포 후 6개월 뒤 시행된다. 이용자 피해 보호와 불만 처리 의무 등을 새로 둔다([율촌, 2026-10-08](https://www.yulchon.com/ko/resources/publications/newsletter-view/45445/page.do)).
- 등급 분류: 게임산업법에 자체등급분류사업자 조문(제21조의2)이 있다. 개인과 중소 개발사는 수수료 50% 감면이 있었다([게임메카, 2023-10-04](https://www.gamemeca.com/view.php?gid=1741742), 지금도 같은지 확인한다).
- 확인하지 못한 것: 게임산업법 시행령 별표 2 제8호와 제12조의3 원문, 게임물관리위원회의 등급 분류 절차(사이트가 자동 조회를 막아 읽지 못했다), 스토어 앱의 자체 등급으로 충분한지, 웹 버전을 따로 신청해야 하는지, 웹보드 규제의 현행 숫자.

### 확인하지 않고 출시하는 것

전문가 확인 없이 출시하고 문제가 되면 그때 고친다(사용자 결정, 2026-11-06). 아래는 답을 받지 않은 질문이다. 문제가 되면 여기부터 본다.

1. **참가비와 승패 보상.** 유상 엽전을 참가비로 내고 승패에 따라 다른 보상을 받는 구조가 베팅·배당이나 재산상 이익·손실에 해당하는지. 무상만 받는 안과 참가비를 없애는 안을 검토한 뒤 산 엽전도 쓰는 안을 사용자가 골랐다(2026-11-06). 문제가 되면 참가비를 무상 엽전에서만 받거나 없앤다.
2. **유료 놓아보기와 시간 연장.** 엽전으로 대국 중 혜택을 사는 것이 등급 분류나 사행성 판단에 영향을 주는지.
3. **본인인증.** 장기고가 제12조의3의 대상인지, 대상이면 본인인증 없이 출시할 수 있는 예외가 있는지. 나라별 연령 기준, 14세 확인을 동의 문구로 해도 되는지.
4. **등급 분류.** 앱과 웹을 각각 어떻게 받는지, 비용.
5. **처리방침과 약관.** 국외 이전 근거, 전 세계 출시에 따른 GDPR 등 추가 의무, 유상 엽전 환불 조항.
6. **세무.** 업종 추가, 통신판매업 신고, 스토어 정산 매출의 부가세.
