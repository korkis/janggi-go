# 채팅과 신고

채팅, 메시지 검사, 신고, 제재 방식이다. 각 항목은 **확정**, **초안**, **미정**으로 표시한다.

## 채팅 종류 — 확정

| 채팅 | 참여자 |
|---|---|
| 로비 채팅 | 로비에 들어온 로그인 사용자. 대국실의 채팅 탭이다 |
| 대국 채팅 | 두 대국자 |
| 관전 채팅 | 대국을 관전하는 로그인 사용자 |

- 로그인하지 않은 관전자는 채팅을 읽을 수 없고 쓸 수도 없다.
- 대국 중에는 대국자에게 관전 채팅을 보여주지 않는다. 관전자가 다음 수를 알려주는 훈수를 막기 위해서다. 대국이 끝나면 대국자도 볼 수 있다.

## 메시지 검사 — 확정

- 모든 채팅 메시지는 서버(Functions)를 거쳐 저장한다. 앱이 채팅 경로에 직접 쓰지 않는다.
- 서버는 OpenAI Moderation API와 자체 금칙어 목록으로 메시지를 검사한다. 자체 금칙어는 Moderation API가 놓치는 한국어 은어와 초성 욕설을 거른다.
- 검사에 걸린 메시지는 채팅에 저장하지 않고 보낸 사람에게 거절 사유를 알린다.
- 걸린 메시지는 보낸 사람, 원문, 검사 결과(걸린 분류와 분류별 점수, 금칙어 일치 여부)를 검사 기록으로 남겨 Admin 웹에서 볼 수 있게 한다.
- 채팅 내용이 해외 서비스(OpenAI)로 전송되므로 개인정보처리방침에 국외 이전으로 고지한다.
- 자체 금칙어를 먼저 보고, 걸리면 OpenAI에 보내지 않는다. 금칙어는 영문을 소문자로 바꾸고 끼워 넣은 숫자·기호를 지운 뒤, 한 글자씩 띄어 쓴 것("씨 발", "ㅅ ㅂ")만 붙여서 찾는다. 두 글자 이상 낱말끼리는 붙이지 않아 "아저씨 발"처럼 낱말 경계에서 금칙어가 생기지 않는다. "시발점"처럼 금칙어를 품은 평범한 낱말은 예외 목록으로 뺀다(2026-11-03 구현).
- OpenAI를 부르지 못하면 메시지를 저장하지 않고 "잠시 후 다시" 안내를 보낸다. 검사하지 않은 메시지를 내보내지 않기 위해서다.

### 실제 검사 확인 — 2026-11-03

에뮬레이터에서 실제 OpenAI(`omni-moderation-latest`)로 확인했다.

- 평범한 장기 채팅("잘 부탁합니다", "마 빠르시네요", "미친 수네요", "차 떼고 둡시다" 등 10개)은 모두 통과했다. 가장 높은 점수는 violence 0.08 정도다.
- OpenAI가 거는 것: 대놓고 하는 한국어 모욕("너 진짜 멍청하다", "꺼져 쓰레기야", "장애인처럼 두네"), "죽어버려", 영어 욕설.
- OpenAI가 놓치는 것: 혐오 은어("한남충", "김치녀", "틀딱"), 패드립("느그 애미", "니 애미 뒤졌냐"), 은어 위협("뒤져라", "대가리 깨져라", "너네 집 찾아간다"), 변형 욕설("시바", "씨빠", "ㄲㅈ", "ㅗㅗ"), 점수가 0.3대에 머무는 모욕("닥쳐 이 벌레야", "너같은 건 살 가치가 없어").
- **미정:** 놓치는 표현을 자체 금칙어에 더할지, harassment 같은 분류에 OpenAI 기본보다 낮은 기준값을 둘지.

## 신고 — 초안

- 사용자는 채팅 메시지를 신고할 수 있다. 신고에는 해당 메시지와 앞뒤 메시지(각각 5개), 그 메시지의 검사 결과를 함께 저장한다. 한 사람이 한 메시지를 여러 번 신고해도 신고 하나로 남긴다.
- 사용자는 다른 사용자를 차단할 수 있다. 차단한 사용자의 메시지와 대국 신청은 보이지 않는다.
- 대국 중 상대의 채팅을 끌 수 있다. 그 대국 화면에서만 숨기고 저장하지 않는다(2026-11-03 구현).

## Admin 웹 처리 — 초안

- 신고 대기열과 검사 기록을 Admin 웹에서 본다.
- 신고 상세 화면에는 다음을 함께 보여준다.
  - 신고된 메시지와 앞뒤 대화
  - 검사 결과(분류와 점수)
  - 피신고자의 과거 신고·검사 기록과 제재 이력
- Admin이 고를 수 있는 조치는 다음과 같다.

| 조치 | 내용 |
|---|---|
| 무혐의 | 신고를 닫는다 |
| 경고 | 피신고자에게 경고를 보낸다 |
| 채팅 제한 | 정해진 기간 동안 모든 채팅을 막는다 |
| 이용 정지 | 정해진 기간 동안 로그인 후 대국과 채팅을 막는다 |
| 영구 정지 | 계정 이용을 영구히 막는다 |

- 모든 조치는 사유를 입력하고 확인 단계를 거친다. 조치 기록은 남긴다.

## 자동 제재 — 초안

- 서버가 검사 기록과 신고 누적을 기준으로 제재를 자동으로 거는 기능이다.
- 설정으로 켜고 끌 수 있으며 **기본값은 꺼짐**이다. Admin 웹에서 바꾼다.
- 꺼져 있으면 모든 제재는 Admin이 직접 건다.
- **미정:** 자동 제재 기준(예: 24시간 안에 검사에 N번 걸리면 채팅 제한 24시간)과 자동으로 걸 수 있는 조치의 범위.

## 설정 저장 — 확정

설정 저장 원칙은 [dev_rules.md](./dev_rules.md)의 "설정 저장"을 따른다.

- 자동 제재 사용 여부는 운영하면서 바꾸는 값이므로 Firestore `configs/app` 문서에 둔다.

| 필드 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `autoSanctionEnabled` | boolean | `false` | 자동 제재 사용 여부 |

- Moderation 모델 이름처럼 운영 중 바꿀 일이 없는 값은 `server/functions`의 `config.ts`에 둔다.
- 자동 제재 기준값처럼 알려지면 검사를 피하는 데 악용될 수 있는 값은 `configs/app`(앱이 읽을 수 있음)에 두지 않는다.

## 보관 기간 — 확정

- 채팅 기록은 90일 보관한 뒤 지운다.
- 검사 기록은 1년 보관한 뒤 지운다.
- 신고된 메시지와 앞뒤 대화는 신고 처리가 끝날 때까지 따로 보관한다. 처리가 끝난 신고 기록의 보관 기간은 검사 기록과 같다.
- 보관 기간은 개인정보처리방침에 적는다.

## 제재 단계와 안내 — 확정

- 제재는 경고 → 1일 → 7일 → 30일 → 영구 정지 순으로 한 단계씩 올린다. Admin은 사안이 무거우면 단계를 건너뛸 수 있다.
- 제재받은 사용자가 앱을 켜거나 대국·채팅을 하려 할 때 팝업으로 사유와 끝나는 날을 알린다.
- 이의 제기는 운영 이메일로 받는다. 팝업에 이메일 주소를 보여준다.

## 미정

- 자동 제재 기준.
