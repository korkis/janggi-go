# 수익 모델

파는 상품, 광고 위치, 광고 보상, 가격 방침이다. 큰 방향은 [plan.md](./plan.md)의 수익 모델을 따르고, 세부는 이 문서에서 정한다.

각 항목은 **확정**, **제안**, **미정**으로 표시한다.

## 원칙 — 확정

- 강제 광고(판 사이 전면광고, 강제 영상광고)는 넣지 않는다. 카카오장기의 가장 큰 약점이라 이것을 빼는 것이 장기고의 차별점이다.
- 대국 결과 자체를 돈으로 바꾸는 상품(급수 보호권 등)은 팔지 않는다. 시간 연장은 여기에 해당하지 않는다. 시간을 더 써도 실력 차이는 넘을 수 없다.
- 확률형 아이템(뽑기)은 팔지 않는다.
- 구독 상품은 두지 않는다.
- 묶음 상품은 두지 않고 하나씩 판다.

## 상품

| 상품 | 상태 | 방식 | 가격 |
|---|---|---|---|
| 나무 장기알 | 확정 | 한 번 사면 영구 | 4,900원 |
| 알루미늄 장기알 | 확정 | 한 번 사면 영구 | 4,900원 |
| 광고 제거 | 제안 | 한 번 사면 영구 | 5,900원 |
| 시간 연장 | 초안 | 쓸 때 엽전을 낸다 | 1회 30엽전 |

- 나무와 알루미늄은 등급 차이가 없어서 같은 값에 판다. 사용자는 취향으로만 고른다.
- 기물 이미지와 폴더 이름은 [ui.md](./ui.md)의 기물 재질을 따른다.

### 기물 스킨 표시 — 제안

- 내가 고른 기물은 상대와 관전자에게도 보인다. 대국마다 상대가 보게 되므로 그 자체가 광고다.
- 설정에 "상대 기물은 기본 기물로 보기"를 둔다. 낯선 기물을 불편해하는 사용자를 위한 것이다.

### 광고 제거 — 제안

- 배너 광고를 없앤다.
- 보상형 광고의 보상을 광고를 보지 않고 바로 받는다. 하루 횟수 제한은 광고를 볼 때와 같다.

### 시간 연장 — 초안

세부 규칙은 [game/time.md](./game/time.md)의 시간 연장을 따른다.

- 연장권을 따로 팔거나 쌓아 두지 않고 쓸 때 엽전을 낸다(2026-11-05 초안). 재화를 엽전 하나로 두기 위해서다. 광고와 현금은 모두 엽전을 거친다.
- 엽전 전체를 3단계에서 다시 세세하게 기획한다.

## 엽전 — 제안

앱 안 재화는 엽전 하나만 둔다. 대국마다 조금씩 쓰고, 이기거나 꾸준히 들어오면 늘어난다. 부담은 적게 두고, 잃는 사람만 조금씩 줄게 한다(2026-11-04 방향 확정, 숫자는 초안).

### 얻고 쓰는 양 — 초안

| 항목 | 엽전 |
|---|---|
| 가입 | +500 |
| 대국 참가 | −10 |
| 대국 끝남 | 승 +20, 무승부 +10, 패 +5 (참가비를 빼면 승 +10, 무 0, 패 −5) |
| 출석 | 하루 +30, 7일 연속째 +100 |
| 보상형 광고 | +30, 하루 5번까지 |
| 바닥 구제 | 10 미만이면 하루 한 번 +100 |

- 하루 5판을 모두 져도 출석만으로 메워진다. 엽전이 없어서 대국을 못 하는 일은 없게 한다.
- 참가비는 빠른 대국과 신청 대국에서만 받는다. 방·링크 대국(방송용)은 받지 않는다. 방송 유입이 핵심 전략이고, 사람이 적은 출시 초기에 매칭을 줄이지 않기 위해서다.
- 대국 시작 직후 상대가 나가 대국이 성립하지 않으면(상차림 중 취소 등) 참가비를 돌려준다.
- 재대국에는 따로 값을 매기지 않는다.
- 숫자는 출시 전에 광고 단가와 서버 비용을 보고 맞춘다.

### 쓰는 곳

- 대국 참가비
- 시간 연장
- 유료 기물 7일 체험. 써보다가 구매로 넘어가게 하는 장치다.
- 닉네임 변경. 첫 변경은 무료이고 두 번째부터 엽전을 쓴다([screens.md](./screens.md)의 내 정보). 필요한 양은 미정이다.

### 현금 충전 — 제안

- 작은 묶음 몇 가지만 판다. 예: 1,200원에 300 안팎부터. 값과 개수는 미정이다.
- 묶음 상품을 두지 않는다는 원칙은 기물·광고 제거 같은 상품 묶음에 대한 것이다. 엽전 개수 단위는 여기에 해당하지 않는다.

### 지킬 선 — 확정

- **엽전은 사용자끼리 오가지 않는다.** 이긴 사람이 진 사람의 엽전을 가져가는 방식(판돈)은 쓰지 않는다. 참가비는 시스템이 받고, 보상은 시스템이 준다. 판돈처럼 보이면 웹보드게임 사행성 규제에 걸릴 위험이 있다.
- 선물, 거래, 현금이나 상품권으로 바꾸기는 없다.
- 산 엽전(유상)과 받은 엽전(무상)을 나눠 기록한다. 쓸 때는 무상부터 쓴다. 산 뒤 쓰지 않은 유상 엽전의 청약철회(7일)와 환불에 대비하기 위해서다.
- 엽전으로 확률형 아이템을 사게 하지 않는다.
- 엽전 지급과 차감은 서버(Cloud Functions, 대국 서버)에서만 한다. 앱에서 바꾸지 않는다.
- 출시 전에 게임물 등급 분류와 웹보드게임 규제에 해당하는지 전문가에게 확인한다.

## 보상형 광고

| 보상 | 상태 | 위치 | 비고 |
|---|---|---|---|
| 엽전 | 제안 | 상점 "엽전 받기" | 하루 5회 안팎 |
| AI 복기 추가 1판 | 제안 | 대국 결과 화면 "AI 복기 보기 (광고 보고 무료)" | AI 복기가 들어가는 4단계부터 |

- 보상은 AdMob 서버 콜백(SSV)으로 검증한 뒤 Cloud Functions에서 지급한다. 앱에서 지급하지 않는다.
- AI 복기는 하루 무료 N판 + 광고로 추가하는 방식으로 운영한다. 무료 판 수와 광고로 추가할 수 있는 판 수는 서버 비용을 보고 정한다(미정).

## 광고 위치 — 제안

| 위치 | 광고 | 이유 |
|---|---|---|
| 대국 화면 | 없음 | 잘못 누르기 쉽고, 대국 중 광고는 신뢰를 깎는다 |
| 대국 결과 화면 | 보상형 버튼만 | 보고 싶은 사람만 본다 |
| 상점 | 보상형 | |
| 홈, 내 기보 목록 | 하단 배너 1개 | 버튼과 충분히 떨어뜨려 둔다 |
| 관전 화면 | 하단 배너 | 로그인 없이 보는 관전자가 많아 방송 유입을 수익으로 바꾸는 자리다 |
| 판 사이 전면광고 | 없음 | 원칙 |

## 가격 방침 — 제안

카카오장기는 장기알을 10만 원, 50만 원에 판다. 고래 사용자에게 파는 전략이다. 장기고는 처음부터 따라가지 않는다.

- 비싼 기물은 자랑할 상대가 있어야 팔린다. 사용자가 적은 출시 직후에는 거의 팔리지 않고 "비싼 앱"이라는 인상만 남는다.
- [plan.md](./plan.md)에서 카카오장기의 약점으로 "비싼 스킨"을 잡아 두었다. 같은 가격으로 시작하면 이 차별점이 사라진다.

사용자가 모이면 고급 라인을 따로 연다.

- 대추나무, 회양목처럼 실제 고급 장기알에 쓰는 나무로 만든 명품 나무 장기알. 나무가 장기 감성에 가장 잘 맞는다.
- 한정 수량과 일련번호, 방송인 콜라보 기물.
- 가격은 3만~10만 원대. 프로필과 대국 화면에서 눈에 띄게 표시한다.
- 4,900원 기본 기물과 함께 두면 서로 가격을 받쳐 준다.

## 결제 — 제안

- 앱 결제는 RevenueCat으로 안드로이드와 iOS 영수증 검증을 맡긴다. 산 내역은 Firebase 계정에 묶어서 안드로이드, 아이폰, 웹 어디서든 쓴다.
- 앱 안의 디지털 상품은 스토어 결제가 의무다(수수료 15~30%).
- 웹 버전은 국내 PG(예: 토스페이먼츠)를 붙여 수수료를 낮추는 것을 검토한다.
