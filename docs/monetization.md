# 수익 모델

파는 상품, 광고 위치, 광고 보상, 가격 방침이다. 큰 방향은 [plan.md](./plan.md)의 수익 모델을 따르고, 세부는 이 문서에서 정한다.

각 항목은 **확정**, **제안**, **미정**으로 표시한다.

## 원칙 — 확정

- 강제 광고(판 사이 전면광고, 강제 영상광고)는 넣지 않는다. 카카오장기의 가장 큰 약점이라 이것을 빼는 것이 장기고의 차별점이다.
- 대국 결과 자체를 돈으로 바꾸는 상품(급수 보호권 등)은 팔지 않는다. 시간 연장과 대국 중 놓아보기는 여기에 해당하지 않는다. 시간을 더 써도, AI 없이 시계가 흐르는 동안 스스로 수를 읽어도 실력 차이는 넘을 수 없다.
- 확률형 아이템(뽑기)은 팔지 않는다.
- 구독 상품은 두지 않는다.
- 묶음 상품은 두지 않고 하나씩 판다.

## 상품

| 상품 | 상태 | 방식 | 가격 |
|---|---|---|---|
| 나무 장기알 | 확정 | 한 번 사면 영구 | 4,900원 |
| 알루미늄 장기알 | 확정 | 한 번 사면 영구 | 4,900원 |
| 광고 제거 | 확정 | 한 번 사면 영구 | 4,900원 |
| 시간 연장 | 확정 | 쓸 때 엽전을 낸다 | 1회 30엽전 |
| 대국 중 놓아보기 | 확정 | 쓸 때 엽전을 낸다 | 판당 30엽전 |

- 나무와 알루미늄은 등급 차이가 없어서 같은 값에 판다. 사용자는 취향으로만 고른다.
- 기물 이미지와 폴더 이름은 [ui.md](./ui.md)의 기물 재질을 따른다.

### 기물 표시 — 확정 (2026-11-07)

- 내가 고른 기물은 상대와 관전자에게도 보인다. 대국마다 상대가 보게 되므로 그 자체가 광고다. 상대 기물을 기본 기물로 바꿔 보는 설정은 두지 않는다(사용자 결정).
- 대국을 만들 때의 기물을 그 대국 내내 쓴다. 대국 중에 기물을 바꾸거나 환불받아도 그 판은 그대로다.
- 기보처럼 대국자의 기물을 저장하지 않는 판은 내가 고른 기물로 그린다. 관전 목록의 작은 판은 기본 기물이다.
- 체험은 두지 않는다. 상점에서 기물 모습을 보여주는 것으로 충분하다(사용자 결정, 2026-11-07). 처음 수익 모델 문서(2026-11-02)에 있던 100엽전 7일 체험을 뺐다.
- 기물을 사면 바로 그 기물을 쓴다.

### 광고 제거 — 확정 (2026-11-06)

- 배너 광고만 없앤다. 보상형 광고는 보고 싶을 때 보는 것이라 그대로 둔다.
- 보상을 광고 없이 바로 주면 하루 150엽전(한 달 4,500엽전, 충전가로 18,000원어치)을 계속 받아 충전이 필요 없어지므로 넣지 않는다.

### 시간 연장 — 확정

세부 규칙은 [game/time.md](./game/time.md)의 시간 연장을 따른다.

- 연장권을 따로 팔거나 쌓아 두지 않고 쓸 때 엽전을 낸다(2026-11-05). 재화를 엽전 하나로 두기 위해서다. 광고와 현금은 모두 엽전을 거친다.

## 엽전 — 확정

앱 안 재화는 엽전 하나만 둔다. 대국마다 조금씩 쓰고, 이기거나 꾸준히 들어오면 늘어난다. 부담은 적게 두고, 잃는 사람만 조금씩 줄게 한다(2026-11-04 방향, 2026-11-05 숫자).

### 얻고 쓰는 양 — 확정 (2026-11-05)

| 항목 | 엽전 |
|---|---|
| 가입 | +300 |
| 대국 참가 | −10 |
| 대국 끝남 | 승 +12, 패 0 (참가비를 빼면 승 +2, 패 −10) |
| 출석 | 하루 +30, 7일 연속째 날은 +30 대신 +100 |
| 보상형 광고 | +30, 하루 5번까지 |

숫자를 정한 기준(승 +12·패 0은 사용자 확인, 2026-11-06).

- 풀을 죽일 만큼 조이지 않으면서, 아이템을 많이 쓰거나 아주 많이 두는 사람은 광고나 충전으로 이어지게 한다.
- 승률 50%면 판당 평균 −4다. 출석이 하루 평균 40쯤이므로 하루 10판(약 3시간)까지는 본전이다. 20판이면 하루 −40이라 가입 300이 8일쯤에 바닥나고, 그 뒤로는 광고 2번쯤이 필요하다.
- 하루 5판을 두는 사람은 승률 30%여도 출석으로 메워진다.
- 이기면 조금씩 늘고 지면 아깝게 해서 승부욕을 건드린다.
- 다 잃어도 다음 날 출석 +30으로 전패 기준 3판은 둔다. 승 +15·패 +5는 승률 50%면 판수로 줄지 않고, 승 +18·패 0은 약한 사람만 줄고 판돈처럼 보여 고르지 않았다.
- 참가비보다 엽전이 적으면 대국을 시작하지 못하고 "엽전이 모자라요"를 보여준다(2026-11-06 사용자 결정). 상점으로 가는 버튼을 이 창에 붙였다(2026-11-07 구현). 충전을 멈췄으면 상점에서 해결할 수 없으므로 붙이지 않는다. 광고 버튼은 순서 6에서 붙인다. 바닥 구제는 없앴다. 출석이 같은 역할을 하고 지급 경로가 늘어 복잡해지기 때문이다.
- 산 엽전도 참가비로 쓴다(2026-11-06). 쓰는 순서는 다른 곳과 같이 무상부터다.
- 참가비와 보상은 빠른 대국, 신청 대국, 방·링크 대국 모두 같다(2026-11-06 사용자 결정). 무료 대국으로 몰리지 않게 하기 위해서다. 두 사람이 20을 내고 12를 받으므로 두 계정으로 불릴 수 없고, 방송 시청자는 가입 300이 있어 링크로 처음 들어와도 막히지 않는다.
- 대국 시작 직후 상대가 나가 대국이 성립하지 않으면(상차림 중 취소 등) 참가비를 돌려준다. 기준은 수가 하나도 없이 끝난 대국이다. 두 사람 모두에게 낸 그대로(무상은 무상으로, 유상은 유상으로) 돌려주고 보상은 없다(2026-11-06 구현).
- 재대국에는 따로 값을 매기지 않는다. 보통 대국과 같이 참가비와 보상을 적용한다(사용자 확인, 2026-11-06).
- 하루는 서울 시간 0시에 바뀐다(2026-11-06 구현). 기기 시계를 믿지 않기 위해 서버가 정한다.
- 출석은 앱을 열면 저절로 받고 화면 아래에 잠깐 알린다(사용자 결정, 2026-11-06). 연속 7째 날에 +100을 받으면 다음 날 1째 날로 돌아가고, 하루를 빠뜨려도 1째 날부터 다시 센다.
- `entryFeeEnabled`를 끄면 참가비를 받지 않고 모자라도 막지 않는다. 대국 보상은 그대로이므로 줄이려면 보상 숫자를 함께 바꾼다.
- 숫자는 `configs/app`에 두어 출시 후에도 앱 업데이트 없이 바꾼다. 조였다가 푸는 쪽이 불만이 적으므로 잔액 분포를 보고 푼다.
- 출시 후 Admin 웹에서 시간 연장과 놓아보기를 쓰는 비율, 사용자별 잔액 분포, 하루 광고 시청 수를 본다.

### 현금 충전 — 확정 (2026-11-05)

| 값 | 엽전 |
|---|---|
| 1,200원 | 300 |
| 3,900원 | 1,100 |
| 9,900원 | 3,000 |

- 작은 묶음만 판다. 값은 스토어 가격 단계에 맞춰 조금 바뀔 수 있다.

### 지킬 선 — 확정

- **엽전은 사용자끼리 오가지 않는다.** 이긴 사람이 진 사람의 엽전을 가져가는 방식(판돈)은 쓰지 않는다. 참가비는 시스템이 받고, 보상은 시스템이 준다. 판돈처럼 보이면 웹보드게임 사행성 규제에 걸릴 위험이 있다.
- 선물, 거래, 현금이나 상품권으로 바꾸기는 없다.
- 산 엽전(유상)과 받은 엽전(무상)을 나눠 기록한다. 쓸 때는 무상부터 쓴다. 산 뒤 쓰지 않은 유상 엽전의 청약철회(7일)와 환불에 대비하기 위해서다.
- 엽전으로 확률형 아이템을 사게 하지 않는다.
- 엽전 지급과 차감은 서버(Cloud Functions, 대국 서버)에서만 한다. 앱에서 바꾸지 않는다.
- 게임물 등급 분류와 웹보드게임 규제, 참가비 구조의 해석은 전문가 확인 없이 출시한다(사용자 결정, 2026-11-06). 문제가 되면 그때 고친다([release.md](./release.md)의 확인하지 않고 출시하는 것).

## 웹 광고 — 확정 (2026-11-06)

앱은 AdMob(`google_mobile_ads`)을 쓴다. 웹은 광고 없이 공개하고, 승인 결과를 보고 넣는다.

- 가벼운 HTML 페이지([release.md](./release.md)의 HTML 페이지)로 AdSense 사이트 승인과 H5 Games Ads 베타를 신청한다.
- 자동 광고는 쓰지 않고, 넣더라도 대국 화면에는 넣지 않는다.
- 웹 광고가 들어오기 전까지 웹 관전 화면의 배너 수익은 없다.

2026-11-06에 확인한 것과 못한 것이다.

- 공식 [`google_adsense`](https://pub.dev/packages/google_adsense) 패키지는 웹 게임 전용이고 H5 Games Ads 베타 승인을 받아야 쓴다. 고정 배너 위젯은 초대제이며 신청을 받지 않는다.
- [H5 Games Ads](https://support.google.com/adsense/answer/9959170)는 전면 광고와 보상형만 있다. 배너는 없고, 전면 광고는 쓰지 않으므로 보상형만 대상이다.
- [AdSense 정책](https://support.google.com/adsense/answer/48182?hl=ko)은 콘텐츠 기반이 아닌 페이지의 광고를 금지한다. Flutter 화면에 직접 끼운 배너가 여기에 걸릴 수 있다고 보았다. 실제 적용 여부는 확인하지 못했다.
- 확인하지 못한 것: H5 Games Ads 승인 조건, 웹 보상형의 서버 검증 방법. 앱의 [AdMob 서버 검증](https://developers.google.com/admob/android/ssv)에 해당하는 것을 찾지 못했으므로 웹 보상형을 넣을 때 엽전 지급 방법을 다시 정한다.

## 가격 방침 — 제안

카카오장기는 장기알을 10만 원, 50만 원에 판다. 고래 사용자에게 파는 전략이다. 장기고는 처음부터 따라가지 않는다.

- 비싼 기물은 자랑할 상대가 있어야 팔린다. 사용자가 적은 출시 직후에는 거의 팔리지 않고 "비싼 앱"이라는 인상만 남는다.
- [plan.md](./plan.md)에서 카카오장기의 약점으로 "비싼 스킨"을 잡아 두었다. 같은 가격으로 시작하면 이 차별점이 사라진다.

사용자가 모이면 고급 라인을 따로 연다.

- 대추나무, 회양목처럼 실제 고급 장기알에 쓰는 나무로 만든 명품 나무 장기알. 나무가 장기 감성에 가장 잘 맞는다.
- 한정 수량과 일련번호, 방송인 콜라보 기물.
- 가격은 3만~10만 원대. 프로필과 대국 화면에서 눈에 띄게 표시한다.
- 4,900원 기본 기물과 함께 두면 서로 가격을 받쳐 준다.

## 결제 — 확정 (2026-11-06)

- 출시 때는 앱 결제만 연다. RevenueCat으로 안드로이드와 iOS 영수증 검증을 맡긴다. 산 내역은 Firebase 계정에 묶어서 안드로이드, 아이폰, 웹 어디서든 쓴다.
- 앱 안의 디지털 상품은 스토어 결제를 쓴다. 앱 안에서 웹 결제를 안내하지 않는다.
- 웹 상점은 상품을 보여주고 구매 자리에 "앱에서 살 수 있어요"를 둔다.
- 기존 사업자로 판다. 사용자가 구글과 애플에서 유료 상품을 판 경험이 있다.
- 스토어 수수료를 줄이는 소규모 사업자 프로그램은 애플과 구글에 각각 신청한다. 조건은 신청 때 확인한다.

### 환불 — 확정 (2026-11-07)

환불은 스토어가 받고 서버는 RevenueCat이 알려 주는 대로 지급한 것을 돌려받는다. 앱에서 환불을 받지 않는다.

- 충전: 유상에서 먼저 뺀다. 모자라면 무상에서 빼고, 그래도 모자라면 잔액이 음수가 된다(사용자 결정). 충전하고 쓴 뒤 환불받는 것을 되풀이해 공짜로 쓰지 못하게 하기 위해서다.
- 잔액이 음수면 참가비를 낼 수 없어 대국을 시작하지 못한다. 출석과 대국 보상, 새 충전으로 메운다. 새로 충전한 유상으로 쓸 때는 빚이 먼저 갚인다.
- 기물과 광고 제거: 없앤다. 쓰던 기물이면 기본 기물로 돌아간다. 다른 스토어에서 또 산 것이 남아 있으면 그대로 둔다.
- 계약 전에 기한과 방법을 알리도록 상점 화면에 청약철회 안내를 둔다([release.md](./release.md)의 약관에 넣을 것).

### 웹 결제는 나중에 다시 본다

사용자가 모이고 외부 결제 규정이 정리되면 본다. 2026-11-06에 확인한 것과 못한 것이다.

- Google Play 정책은 앱 안에서 다른 결제로 이어지는 웹페이지로 바로 링크하는 것을 금지한다. 한국 사용자에게는 앱 안 대체 결제를 허용하고 수수료를 4% 낮춘다(예: 15% → 11%)([Play Console 도움말](https://support.google.com/googleplay/android-developer/answer/10281818?hl=en)).
- 한국 규제기관이 2026년 10월 구글과 애플에 과징금을 물리고 3개월 안에 외부 결제 링크를 허용하라고 명령했다. 두 회사는 대응을 검토 중이다([The Next Web, 2026-10-30](https://thenextweb.com/news/google-apple-fined-south-korea-in-app-payments), 2차 보도).
- RevenueCat은 월 매출 $2,500까지 무료이고 넘으면 매출의 1%다([요금](https://www.revenuecat.com/pricing)).
- [Stripe 지원 국가](https://stripe.com/global)에 한국이 없다. Paddle은 [원화 결제](https://developer.paddle.com/concepts/sell/supported-currencies)를 지원하지만 한국 판매자를 받는지는 확인하지 못했다.
- 토스페이먼츠의 [퀵오픈](https://www.tosspayments.com/quick-open)은 포인트 충전과 사행성 업종을 받지 않는다. 일반 심사에서 엽전 판매를 받는지는 문의해야 한다.
- 확인하지 못한 것: 웹에서 산 엽전을 앱에서 쓰는 것이 스토어 정책에 맞는지, RevenueCat 웹 결제의 대행사와 Flutter 웹 지원.
